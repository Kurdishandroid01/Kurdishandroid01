- 🎮 **Games:** یاری دامەی کوردی و یارییە فکرییە بەسوودەکان.
- 🎬 **Video & Media Players:** ئەپی Arc Player و پلەیەرە پێشکەوتووەکانی میدیا.
- 🎨 **Art & Design & Browsers:** ئەپەکانی گرافیک، دیزاین و وێبگەڕە تایبەتەکان.
